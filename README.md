❤️ Projeto — Análise de Risco de Ataque Cardíaco
📘 Descrição
Este projeto tem como objetivo analisar características clínicas, demográficas e de estilo de vida de pacientes para identificar padrões relacionados ao risco de ataque cardíaco.
A iniciativa busca compreender quais fatores estão mais associados ao aumento desse risco, utilizando técnicas de análise de dados e aprendizado de máquina.

🎯 Problema e Objetivo
Problema: compreender quais características dos pacientes apresentam relação direta com o risco de ataque cardíaco.

Objetivos:

Explorar a base de dados e identificar padrões e correlações entre variáveis.

Preparar os dados para o desenvolvimento de um modelo de classificação capaz de prever o risco de ataque cardíaco.

Gerar insights que possam apoiar decisões clínicas e políticas de prevenção.
